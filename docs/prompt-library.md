# 提示词图库

提示词图库是本地优先的提示词沉淀区，用来保存常用提示词、分类标签和关联样图。它和 `画廊`、`Agent` 并列显示，但不会自动生成图片。

## 使用方式

- 在顶部切到 `提示词`。
- 点击 `新建提示词` 手动保存纯文本提示词。
- 在任务卡片或详情页点击 `保存提示词到图库`，会把任务提示词和输出图片保存为图库条目。
- 在图库详情中点击 `使用提示词`，只会把提示词填入 Gallery 输入框。

使用提示词时会保留当前参考图、遮罩、参数和 Gallery 批量变量。如果 Gallery 输入框已有不同提示词，会先确认是否替换。

## 和收藏的关系

提示词图库和收藏不会合并。

- 收藏面向任务和图片管理。
- 提示词图库面向提示词复用和样图参考。
- 从收藏夹里的任务保存到图库时，会记录来源收藏夹。
- 收藏夹后续改名、移除任务或删除收藏，不会自动改写图库条目。

## 图片存储

图库条目只保存图片 id，不重复保存 base64。图片仍复用现有 IndexedDB 的 `images` 和 `thumbnails`。

删除图库条目时，只会清理图库独占引用的图片；仍被任务、收藏、Agent、输入草稿引用的图片会保留。

## 备份与恢复

ZIP 备份支持单独勾选 `提示词图库`。

- 导出图库会包含图库条目，以及它引用的图片和缩略图。
- 导入图库会先恢复图片，再合并提示词条目。
- 同 id 条目合并时，保留 `updatedAt` 更新的一条。

## 当前边界

- 第一版只做本地图库，不做云同步和在线市场。
- 第一版提示词是纯文本，不提供 `{{variable}}` 模板引擎。
- 第一版图片来自已生成任务；手动上传图库图片留到后续版本。
